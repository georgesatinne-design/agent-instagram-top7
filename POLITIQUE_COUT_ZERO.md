# Politique impérative : coût supplémentaire 0 €

Illyadera doit fonctionner sans abonnement supplémentaire, API payante, essai à renouvellement automatique, achat d'images ou service d'hébergement facturé. Aucun secret d'une IA payante n'est nécessaire.

- GitHub : dépôt public, runner standard ubuntu-latest. Ne pas activer les runners premium, services payants, LFS payant ou dépassements de stockage. La consommation de stockage des artifacts/caches peut être facturée selon les paramètres du compte : rétention des nouveaux artifacts ramenée à 1 jour ; le budget de facturation doit être fixé à zéro côté propriétaire.
- Buffer : offre Free, maximum 10 posts programmés par canal, 3 canaux. Ne pas augmenter ces plafonds ni souscrire un essai. Source : https://buffer.com/pricing et https://support.buffer.com/articles/how-many-posts-can-i-schedule-in-advance-Kmy2IEecqm
- Rendu Python/Pillow, données publiques, Commons/Openverse/Library of Congress : aucune API facturable ajoutée. Respect des quotas, licences, conditions des sites, échec explicite lorsque le quota est atteint.
- Sources de classement : BDZoom (BD), ActuaLitté/Edistat et Bédé.fr (manga reconstitué), MDCU/BDFugue (comics d'une enseigne). Ne jamais présenter un classement d'enseigne ou une reconstitution comme un palmarès national certifié. Livres Hebdo/GfK est un autre panel ; l'utiliser comme contrôle séparé uniquement pour les données accessibles.
- Pistes à étudier : https://www.edistat.com/ (accès public partiel, pas de souscription), https://www.livreshebdo.fr/meilleuresVentes, https://mang-actu.com/classements-des-ventes/ (vérifier périodicité et nombre de titres). Une source affichant 5 titres ne permet pas d'inventer les deux suivants.

## Anecdotes
Les archives institutionnelles (Institut René Goscinny, Tintin, Schulz Museum, archives Tezuka, BnF, Library of Congress, Cité de la BD) alimentent le repérage des pistes. Les liens collectés restent dans un fichier interne A_VERIFIER ; ils ne sont pas des anecdotes validées. Les faits rédigés à partir de ces sources doivent être exacts, originaux dans la formulation, vérifiables, illustrés par des médias dont les droits sont contrôlés. Ne pas contourner un paywall ni réutiliser les illustrations d'un site par défaut.

Préférer les histoires de création, les détails insolites, les personnages, les choix des auteurs et les évolutions du médium. Exclure les fiches produit triviales. Un créneau vide est préférable à une publication faible ou non vérifiable.
